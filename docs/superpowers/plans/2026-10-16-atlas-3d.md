# Kinesis Atlas 3D implementation plan

**Goal:** Make source anatomy navigable in Kinesis Lab, with PT context and usable web controls.

**Architecture:** Generate pinned, attributed GLB assets and metadata. Keep a reusable Three.js renderer separate from the React workspace and pure state helpers. Reuse existing anatomy/exercise records for context.

- [x] Export musculoskeletal source geometry into whole-body and regional GLBs using a repeatable Blender script; audit mesh counts, bounds, file sizes and asset credits.
- [x] Define typed metadata and pure accent-insensitive search/visibility functions; inspect state precedence for hidden, isolated and disabled layers and manifest consistency.
- [x] Implement lazy client renderer with local Draco decoding, load/error feedback, picking, camera views, focus/reset, responsive sizing and cleanup.
- [x] Implement 3D workspace controls, structure list and inspector, region selection, share link and existing consultation/exercise links.
- [x] Integrate 3D tab and initial muscle selection into existing Atlas without breaking existing tabs.
- [x] Run lint, build and React Doctor; inspect asset metadata. Exercise real model loading, layer/isolate/hide/reset/picking, deep links and desktop/mobile layout; perform independent code review and resolve defects.

## Delivery notes

- 1,031 source structures: 429 muscles, 207 skeletal structures, 395 joint structures. Six GLB bundles have a matching mesh node for every metadata entry; empty face-less source objects are excluded.
- Full bundle: 9,156,940 bytes. Hip bundle: 380,232 bytes. Local Draco decoding, no runtime model CDN.
- `npm run lint` and `npm run build` passed. Browser inspection confirmed real WebGL rendering, Vietnamese search without accents, selection by list and direct picking, isolation/hide/restore and a structure share URL. Layout at 390px has no horizontal page overflow.
- Independent review found six issues (initial focus, bone labels on muscles, cervical mapping, missing hip structures, reset bounds, name punctuation); all were fixed and re-reviewed with no remaining blockers.
- React Doctor full scan: 52/100, 39 warnings across the existing app. New workspace warnings concern component size/complexity. The Canvas promise warning is a confirmed false positive: its chained catch covers import, constructor and awaited model loading. These advisory findings are not an assertion of a clean whole-app scan.
- No automated test suite was added or run during final integration.
- Vietnamese names cover selected common structures (140 translated labels); source English and available Latin names are preserved. No head/visceral model or new clinical validation is claimed. PT region mappings may be absent where the existing library has no appropriate region.
- The app's existing AI connection is not configured in the local preview; links prepare a structure question but do not guarantee AI responses.
