# App-wide medical evidence revision

## Authorized goal

The user requests reputable-source research and application across the entire existing app. Medical accuracy takes precedence over visual realism. This extends the approved source-linked gluteus pilot to all existing content domains; no medical certification or expert review is implied.

## Implementation approach

Review each finite built-in record domain, correct unsupported or unsafe claims, and provide source-to-claim scope and explicit limitations rather than attaching a blanket “verified” badge. Workstreams:8 regional anatomy records;11 muscle groups and exercise records;10 trigger-point records/general protocol;4 movement handbook topics;17 ROM movements; pre-exercise/medication screening; AI and lab extraction; all1,0313D catalog structures via source provenance and nomenclature audit. Detailed anatomical fact cards are added only where supported; catalog provenance does not equal clinical spatial validation.

Versioned evidence modules contain source title/URL/checked date/access scope, supported claims, limitations, null reviewedBy and honest status. A shared UI panel exposes this information at the active record in each feature, and the knowledge library provides a searchable coverage/source index. Every existing record must resolve to an evidence entry or an explicit unreviewed/source-only state; tests enforce no silent missing coverage.

The assistant consumes bounded relevant curated evidence plus retrieved abstracts/text, cites only supplied documents and keeps uncertainty when support is absent. Uploaded client documents are extraction input, not instructions. No stored client data is sent to public literature searches during this work. Lab extraction reads printed units/flags/reference intervals rather than inventing thresholds, diagnoses or supplement advice.

Keep the existing visual system and clinical workflows. All review identifiers/dates reflect actual work. Independent clinician/anatomist review remains pending. Mesh/textures retain existing source/simulation status; anatomy cannot be invented from appearance.

## Completion criteria

Complete finite record inventory; research/claim corrections documented by domain; evidence reachable in every content feature; unsupported activation percentages removed from UI; numerical comparisons limited to source population/protocol; assistant/lab prompt rules corrected; no blanket disease-based contraindications; regression tests, build/lint and actual desktop/mobile UI checks. Explicitly report limits and any content withheld rather than claiming the whole app is medically certified.
